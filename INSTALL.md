# FlowPy — Installation & Usage

## Requirements & running from source
FlowPy runs in its own Python environment (`.venv-build`), so it never
changes your Anaconda installation:
```bash
./packaging/run_dev.sh                 # creates the environment on first run
./packaging/run_dev.sh my_data.fcs     # open FCS files…
./packaging/run_dev.sh analysis.fpw    # …or a workspace
./packaging/run_dev.sh --selftest      # check the scientific libraries
```
Requires Python 3.10+. Dependencies are in `requirements.txt`.

## Established libraries used
| Task | Library |
|---|---|
| Reading FCS 2.0 / 3.0 / 3.1 | **FlowIO** |
| Logicle transform, compensation, spectral OLS unmixing | **FlowUtils** (reference C code) |
| FlowJo `.wsp` and Gating-ML 2.0 import/export; independent recount of gates | **FlowKit** (validated against the Gating-ML 2.0 compliance tests) |
| FlowSOM clustering | **FlowSOM** (official Python port, saeyslab) |
| UMAP / t-SNE, k-means, Gaussian mixtures | **umap-learn**, **scikit-learn** |

## Build the app (like BioStatExplorer)
**macOS** — produces `dist/FlowPy.app`; drag it into Applications:
```bash
./packaging/build_mac.sh
```
**Windows** — push to GitHub; the *Build Windows executable* workflow
(`.github/workflows/build-windows.yml`) uploads `FlowPy.exe` as an artifact.

The icon is generated by `python packaging/make_icon.py`.

## Drawing gates
1. Load an FCS file with **Open FCS**
2. Choose X / Y channels and scale in the plot controls
3. Click one of the gate buttons: **Polygon / Rectangle / Ellipse / Quadrant / Range**
   — an orange bar tells you how to draw; **Esc** cancels
4. Draw on the plot (Polygon: click to add points, click the first point to close)
5. Give the gate a name → it appears in the population tree with its %
6. The plot always shows one population (see the path above the plot).
   **Double-click inside a gate** (or click it in the tree) to open it —
   new gates are drawn inside the population you are looking at.
   Click **All Events** in the tree to go back to the top.

## Editing gates
* **Click a gate** to select it: handles appear. Drag the gate to move it,
  drag a handle to reshape it (polygon points, rectangle corners, range
  edges, the quadrant centre). Ellipses: centre handle moves, the long-axis
  handle resizes **and rotates**, the short-axis handle resizes.
* **Edit Values…** (or right-click a gate in the tree) types exact numbers,
  the name and the colour.
* **Delete / Backspace** removes the selected gate; **Esc** deselects.
* **Edit → Undo / Redo** (⌘Z / ⇧⌘Z) for every gating change, per sample.
* Polygon and ellipse gates can be edited on the scales they were drawn on
  (the hint tells you which).

## Boolean gates
**AND / OR / NOT…** (gate toolbar, *Gating* menu, or right-click in the tree)
combines existing gates: events in **all** (AND), **any** (OR) or **none**
(NOT) of the ticked gates, inside the population being viewed.

## Statistics
Mean, Median, Geometric Mean, SD, Robust SD, CV, Robust CV, Min, Max and any
Percentile, per gate and channel. *Export CSV…* writes all of them.
Robust SD follows FlowJo: half the 15.87–84.13 percentile spread.

## Analysis menu
* **UMAP / t-SNE…** — embeds the population shown; adds channels
  `UMAP-1/2` (or `tSNE-1/2`) that you can plot and gate.
* **Clustering…** — FlowSOM (official implementation: 10×10 SOM →
  metaclusters), k-means or Gaussian mixture. Adds a `Cluster` channel, a gate per cluster (counts,
  %, statistics) and a heatmap of cluster profiles (exportable).
  Turn on *Colour gated events* to see the clusters on a UMAP.
* **Auto Gate on Current Plot…** — finds populations on the 2-D plot shown
  (Gaussian mixture) and draws a rotated ellipse gate around each.
* **Spectral Unmixing…** — mark an unstained control, single-stain controls
  and the samples to unmix; ordinary least squares (FlowUtils) adds one
  `<fluor> (unmixed)` channel per fluorochrome. OLS only: no
  autofluorescence extraction or weighted unmixing.

Computed channels are saved in the workspace file.

## FlowJo and Gating-ML (Gating menu)
* **Import FlowJo Workspace (.wsp)…** — gates (and the compensation matrix)
  for every loaded sample that is in the workspace. A table compares
  FlowPy's counts with FlowKit's gating of the same workspace.
* **Export to FlowJo (.wsp)…** — your samples with their gates and
  compensation; FlowJo finds the FCS files from their saved location. The
  file is read back with FlowKit and compared with your original counts.
  FlowJo keeps one scale per channel, and FlowKit cannot write FlowJo
  ellipse or Boolean gates yet, so: ellipses become polygons following the
  ellipse, polygons drawn on another scale are traced onto the channel's
  scale, Boolean gates are left out (the report lists each case).
* **Import / Export Gating-ML 2.0…** — the standard exchange format; keeps
  ellipses and Boolean gates. Gate names become valid XML IDs ("CD3+" →
  "CD3_"). An imported file is applied like a gating protocol.
* **Verify Counts with FlowKit…** — FlowKit recounts every population of
  every sample independently; any difference is highlighted.

Gates drawn in FlowJo on scales FlowPy doesn't have (FlowJo's default
"biex", hyperlog, arcsinh, other Logicle widths) are imported by following
their outline closely; the comparison table shows whether that matters.

## Gating many samples (protocols)
Each sample keeps its own gates. To gate a whole experiment in one go:
1. **File → Open FCS Folder…** to load all the samples
2. Gate one sample
3. **Apply Gates to Samples** (toolbar, or *Gating* menu) → tick samples → Apply.
   Samples missing a channel the gates use are greyed out and skipped.
4. Click through the samples: the plot stays on the same population and axes.
   Adjust a gate on one sample if needed — the others are not affected.
5. **Batch Statistics** — % parent / count / % total for every population in
   every sample in one table (or the full table with channel medians/means),
   exportable to CSV.

**Gating → Save Gating Protocol…** writes the gate tree to a `.fpg` file;
**Load Gating Protocol…** applies a saved protocol to any samples later
(a `.fpw` workspace can be loaded as a protocol too).

**Copy and paste gates** between samples, workspaces or two FlowPy windows:
* **Edit → Copy Gates** (⌥⌘C) copies the selected gate with its sub-gates
  (nothing selected: all gates). Right-click in the population tree also
  offers *Copy Gate* and *Copy All Gates*.
* Open the other workspace (or switch window), then **Edit → Paste Gates…**
  (⌥⌘V) — or right-click a population → *Paste Gates Here…*. Choose where:
  next to the existing gates, inside a population (pre-set to where the
  gates came from), or replacing all gates; and which samples.
* Derived parameters the gates use are created; samples missing a channel
  are greyed out. Pasting twice gives independent copies (AND/OR/NOT gates
  follow their own copied operands). Undo (⌘Z) takes a paste back.

## Layout (graph builder)
* On the Gating tab, press **＋ Add to Layout** to copy the current plot
* On the **Layout** tab: reorder, duplicate, retitle, change axes/type
* Tick several **samples** and/or **populations** on one plot to
  **overlay** them (histograms → coloured lines, normalised to % of max;
  2-D → coloured dots). *Stagger* offsets overlaid histograms FlowJo-style.
* Options for the selected plot, in four tabs:
  * **Data**: title, type, samples, populations, normalise/stagger
  * **Style**: colour map (Turbo, Jet/FlowJo, Viridis, Blues…), overlay
    palette (incl. colour-blind safe), click a layer to pick its colour,
    dot size/opacity, line width, fill opacity, smoothing, frame, grid
  * **Axes**: channel, scale, custom axis label, axis range (channel units)
  * **Labels**: statistic on the plot (Median, Mean, Geometric Mean, CV,
    Percentile…) marked as a dashed line / cross, event count, stats box
    and legend position, gate names / % / line width, hide title
* **Apply this style to all plots** copies the look of one plot to all
* **Page**: columns, plot size, font and font size, export resolution
  (150/300/600 dpi), transparent background
* **Export figure…** saves the whole page as PNG, PDF or SVG

## Derived parameters (ratios, formulas)
Analysis → **Derived Parameters…** creates a new channel from a formula,
e.g. `[YG5-A] / [BL1-A]` (Quick Ratio fills it in), or
`log10([mKate-A]) - log10([GFP-A])`. Channel names go in square brackets;
allowed: + − × ÷ ** ( ), numbers, log10, ln, log2, sqrt, abs, exp, asinh,
min, max. The new channel can be plotted, gated and exported like any
other, is created in all samples, is recomputed when compensation changes,
and is saved in workspaces and gating protocols (applying a protocol
creates it in the target samples). Undefined results (÷ 0, log of a
negative) are left out of plots and gates.

## Sample sheets (Excel) and plate layouts
**Sample Metadata → Import Excel / CSV…** reads a `.xlsx` (or CSV) file:
* **a table** — first column = sample file name (with or without .fcs) or
  well (B3 / B03), one column per variable (Group, Strain, Dose…). A
  **Name** column renames the samples (the files are not touched).
* **a plate map** — the A–H × 1–12 grid (or 384-well A–P × 1–24), one block
  per variable, named by the text in its top-left corner, just above it,
  or by the sheet name. Samples are matched by well.

**Analysis → Plate Layout…** (⇧⌘P) shows where each sample sits:
* **Wells from**: the sample name — first well-like part (`A03 GFP`) or
  last (`Specimen_001_B03`) —, the FCS file's well keyword, or only a
  Well column you typed. A typed **Well** column always wins (to correct
  one sample).
* **Plate**: 6, 12, 24, 48, 96 or 384 wells (Auto = 96, or 384 if needed).
* **Colour by** any metadata column; duplicates and samples outside the
  plate or without a well are listed. Double-click a well to open it.
* **Show**: two plates side by side — sample names on the left, the
  *Colour by* column (e.g. Group) on the right — or one plate with both.
* **Save Wells as Metadata** adds Well, Row and Column columns — e.g. to
  compare rows in Compare Groups.

## Sample metadata and Compare Groups
**Analysis → Sample Metadata (Groups)…** (⇧⌘M, or the Metadata toolbar
button) is a small spreadsheet: one row per sample, columns such as Group,
Medium, Strain, Timepoint. Fill it by typing, pasting a block from Excel
(⌘V; one value pasted onto a selection fills every selected cell),
**Fill From File Names…** (e.g. "126 - M9 Medium" split on " - " → part 1
"126", part 2 "M9 Medium"), or **Import CSV…** (first column = file
name). The group shows next to each sample in the list, is saved in the
workspace, and is added to **Export Data**.

The **Compare Groups** tab plots one value per sample (Count, % Parent,
% Total, or any statistic of any channel in any population) by group:
bar + points, box + points, points + mean, or a line over a numeric
column (time, dose), optionally coloured by a second column. Error bars
SD / SEM / 95 % CI; tests: Welch's t-test / one-way ANOVA, or
Mann-Whitney / Kruskal-Wallis. Summary table (n, mean, SD, SEM, median,
min, max), figure export (PNG/PDF/SVG) and per-sample values as CSV or
clipboard.

## Full spectrum (spectral cytometers)
Choose **Spectrum** as the plot type: every spectral detector (UV1…R8,
grouped by laser) with the density of events and the median spectrum of
the population. Tick *Colour gated events* to add the median spectrum of
each gated sub-population. In the Layout, a Spectrum plot with several
populations/samples overlays their median spectra (tick *Normalise* to
scale each to peak = 1, handy for comparing fluorophore signatures).
Works with BD (FACSDiscover, "UV1 (375)-A") and Cytek ("UV1-A") naming.

## Figures for Inkscape / Illustrator
Export as **SVG** (or PDF) from the Layout tab, Compare Groups, or the
save icon under the gating plot. Text stays real, editable text (not
outlines), and axes, gates, lines and bars are separate vector objects.
Dense dot clouds and spectrum heatmaps are embedded as one high-resolution
image inside the SVG, so Inkscape stays fast (50,000 separate dots would
make it crawl).

## Large files
Files of 10+ million events are fine: events are stored as float32 (as
recorded by the cytometer, half the memory), shape gates only test the
events near them, and statistics are computed per channel in parallel.
A 10-million-event, 30-channel file opens in under a second and uses
~1.3 GB of memory.

Files over 64 MB (e.g. full-spectrum files: ~800,000 events × 188
channels = 600 MB each) are kept in a **temporary** file on this computer
and memory-mapped instead of held in RAM, so 80 such files (26 GB) work on
a 16–24 GB Mac without swapping. Nothing is kept: the temporary folder is
deleted when FlowPy quits (or at the next start after a crash), and FCS
files are never copied. A file opened again in the same session (e.g. by
re-opening the workspace) isn't read again.

**Opening is instant; events are read in the background** (like
FlowJo). Opening files or a workspace reads only each file's header (a
few KB), so 81 files from a network drive appear in seconds. Their events
are then read one file at a time: the sample you click goes first, then
the others in list order. In the sample list:

| Dot | Meaning |
|---|---|
| grey ring | waiting to be read |
| amber | being read now |
| red | can't be read (hover for why; click it again to retry) |
| none | ready |

Clicking a sample that isn't read yet shows "Reading …" and opens it as
soon as it is ready (small files open immediately). Gating, Apply Gates
to Samples, Export Data, Batch Statistics, FlowJo export, unmixing and
Compare Groups first wait for the samples they need, with a progress bar
and Cancel. Passing network timeouts are retried automatically.

**Network drives**: the total time is set by the connection — at ~9 MB/s
(Wi-Fi / VPN) 26 GB takes about 50 minutes to arrive, on a wired
connection on site several times less — but you can work on the first
samples while the rest arrive. A file is read only once per session.

## Interface tips
* **Toolbar**: Open FCS, Save, Apply Gates to Samples, Metadata, and one
  **Export ▾** menu (data table, figure of the current tab — gating plot,
  layout page or group chart —, this sample's statistics, FlowJo .wsp,
  Gating-ML). Batch Statistics is in the *Gating* menu, Compensation in
  *Edit*.
* **Channel boxes**: type any part of a name (e.g. "yg5") to find it;
  spectral detectors are listed under their laser.
* **Samples**: search box, grouped by your Group column, number of gates
  on the right. Drag the divider to give samples or populations more room.
* **Statistics panel** — *Show*: the channels on the plot (default), all
  fluorescence channels, or channels you choose.
* Controls that don't apply are hidden (no Y channel for a histogram, no
  gate tools on a spectrum). Names are never shortened: lists scroll
  sideways if needed.
* **Layout**: thumbnails of each plot; page size, font and resolution in
  **Page Setup…**.

## Export Data (⌘E)
**Export ▾ → Data — Statistics for All Samples…** (toolbar or File menu) builds a table of exactly
what you need, e.g. the Median of YG5 in "Cells / Singlets / mKate+" for
every sample: tick samples, populations, channels (search box) and
statistics (Count, % Parent, % Total, Mean, Median, Geometric Mean, SD,
Robust SD, CV, Robust CV, Min, Max, Percentile). One row per sample, or one
row per sample × population. **Export CSV…** or **Copy to Clipboard** (paste
into Excel / Prism). The selection is remembered. Empty cells mean the
population isn't gated in that sample.

## Saving
FlowPy works like a document app (Word, FlowJo):
* **File → Save As…** names the workspace (`.fpw`: samples, gates,
  compensation, computed channels, metadata, layout). **Save (⌘S)** writes
  later changes to it; the title bar shows its name (a dot in the red
  close button means unsaved changes).
* The file **only changes when you save**. Opening an old workspace and
  doing something else never overwrites it — before replacing changed
  work, FlowPy asks "Save the changes to …?".
* **Several workspaces at once**: **File → New Window** (⌘N) opens an
  empty window. **Open Workspace…** opens into a new window when this one
  already holds an analysis (a workspace already open just comes to the
  front). **Open FCS** while a workspace is open asks: **New Window** (the
  open one stays as it is) or **Add to** it. Each window saves and keeps
  its recovery copy on its own; closing one leaves the others open.
  *File → Clear This Window* starts over in the same window.
* Unsaved changes are kept in a recovery copy in
  `~/Documents/FlowPy/sessions/`; **File → Recover Last Unsaved Session**
  reopens it (e.g. after a crash).
* **Open Workspace…** (⇧⌘O) reopens a workspace; `FlowPy my_analysis.fpw`
  works too.

## Compensation
The spillover matrix stored in the FCS file is **applied on load** (as in
FlowJo). Edit it with **Edit → Compensation…** or remove it with
**Edit → Remove Compensation**; the choice is saved in the workspace.
The matrix editor imports/exports CSV and can reset to identity.
